    사용설명서

    1. 출장 정보를 입력하세요

      출장 구분을 선택한 뒤 출장일과 복귀일을 입력합니다. 당일 출장은 두 날짜를 같게 지정합니다. 출장자 이름, 소속, 출장 목적을 입력하면 결과 화면과 인쇄물에 표시됩니다.

    2. 출장 구분에 맞는 조건을 입력하세요

      근무지 내 출장은 실제 출장 시간과 차량 이용 조건을 입력합니다.

      근무지 외 출장은 여비 지급 구분과 교통수단을 선택하고, 지급 기준에 맞는 운임을 입력합니다. 숙박한 경우 지역, 박수, 1박 실비를 입력합니다. 지역이나 1박 요금이 다르면 요금 추가를 누릅니다. 장기 체재나 공적 항공마일리지 등은 추가 지급 및 감액 조건을 펼쳐 입력합니다.

    3. 예상 지급액을 확인하세요

      여비 계산하기를 눌러 합계, 항목별 금액과 적용된 조건을 확인합니다. 날짜나 지급 조건을 바꿨다면 다시 계산합니다.

    4. 인쇄하거나 PDF로 저장하세요

      계산 결과 인쇄를 누릅니다. 브라우저 인쇄 창에서 프린터를 선택하거나 PDF로 저장을 선택합니다.
